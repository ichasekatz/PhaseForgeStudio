PhaseForge Studio

CALPHAD pipeline dashboard — browse the workspaces below or start with Setup.

Quick Start
  1. Open Setup — missing packages install automatically; add local paths here
  2. Open Materials Framework → pick elements + lattices → run SQS generation
  3. Open ORCHID → search for experimental data on your system
  4. Open PhaseForgePlus → fit TDB using computed + experimental data
  5. Or use Pipeline Maker to chain all steps in one run
Materials Framework
Generate SQS structures for alloy systems, run MLIP relaxations, and produce fitted TDB databases. Entry point for computed thermodynamic data.
SQSMLIPTDB
PAIPAI
Monte Carlo low-energy structure search using GRACE-2L-OMAT. Finds stable atomic configurations in a composition space. Outputs CONTCAR files.
Structure SearchMonte Carlo
BLADE
Full CALPHAD pipeline: SQS generation → MLIP energies → TDB fitting. Configure elements, lattices, and temperature range — generates a launch-ready TOML.
CALPHADEnd-to-End
ORCHID
Search 2 912 expert-drawn TDB databases and 73 k+ literature thermodynamic values. Fetch phase diagrams, formation enthalpies, and invariant reactions.
Experimental DataLiterature
ORCHID-SAGE
Reproducibility layer for CALPHAD assessments. Browse model recipes, validate ORCHID specs, plan reproductions, and visualize TDB output phase diagrams.
ReproducibilitySAGE
PhaseForge
SQS-based CALPHAD workflow using ATAT + MaterialsFramework. Configure species, lattices, and run parameters. View phase diagrams and trajectory data.
ATATCALPHAD
PhaseForgePlus
Bayesian TDB fitting using ESPEI. Combine computed energies (MF/BLADE) with experimental data (ORCHID) for MCMC-refined CALPHAD parameters.
ESPEIMCMCBayesian
Pipeline Maker
Chain any combination of framework steps into a single run. Shared inputs (elements, system name, TDB path) auto-wire between steps. Live log per step.
AutomationMulti-Framework
Benchmark
Evaluate MLIP accuracy on DFT reference structures. Energy MAE, force MAE, stress MAE, bootstrap CIs, outlier detection, per-composition breakdown.
MLIP AccuracyBenchmarking
Setup
Install Python packages (orchid-mcp, pycalphad, materialsframework, phaseforgeplus, blade) and configure binary paths. Auto-detects local source installs.
InstallConfig
Typical Data Flow
PAIPAI (low-E search) → MF / BLADE (SQS + MLIP → computed TDB) → ORCHID (experimental data) → PhaseForgePlus (ESPEI fit → refined TDB) → ORCHID / SAGE (visualize + reproduce)
Pipeline Maker automates this entire chain in one click.
